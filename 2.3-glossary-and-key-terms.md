## Show Terms

|                      |   |                                                                                                                       |
| -------------------- | - | --------------------------------------------------------------------------------------------------------------------- |
| Sensory Show (S)     |   | Adjusted sound, light and cue intensity for designated sensory session groups. Orange S will appear on audio servers  |
| Normal Show (N)      |   | The everyday sound, light and cue intensity.                                                                          |
| Work Lights/ Hi Bays |   | Light mode for cleaners and dark days. Partially controlled by Show Touch, others manually switched off at breaker.   |
| Show Lights          |   | Lighting state for show sequence                                                                                      |
| STAY ON (Red) label  |   | DO NOT SWITCH OFF                                                                                                     |
| ON/OFF (Green) label |   | Switch on start of day, switch off end of day                                                                         |
| Maglocks             |   | Magnetic locks, triggered during show sequence                                                                        |
| Server Rack          |   | The racks inside the distro where the breakers sit                                                                    |
| Calibration          |   | Resetting the dome so the content appears clearer                                                                     |
| Breaker              |   | Switch to turn on or off powering from the main distro                                                                |
