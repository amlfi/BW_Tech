## **1. Show Control Interfaces**

The show is controlled through a combination of software interfaces, each with a different role.

#### **Primary Interface: ShowTouch**

ShowTouch is the main touchscreen control system used to operate and monitor the show.

It allows operators to:

* View all show areas and their status
* Monitor sequence timers and countdowns
* Trigger or reset specific elements when required

This is the system operators will interact with **most frequently**.

#### **Supporting Interfaces**

* **OBS (Open Broadcaster Software)**\
  Used to mirror the ShowTouch interface onto control room screens and CCTV feeds for visibility.
* **WinScript**\
  Contains the programmed show logic and sequences.\
  ⚠️ Operators should **not interact with this system**, as it controls the core programming of the show.



## **2. Devices**

The control room contains multiple devices used to operate and monitor the show.

#### **Primary Devices**

* **Touchscreen Control Panel (Alcorn McBride)**\
  Main interface for ShowTouch
* **Control Room PC**\
  Runs ShowTouch, OBS, and other systems
* **Large Display Screen (TV)**\
  Mirrors the system for easier monitoring

#### **Portable Devices**

* **iPad / Handheld Tablet**
  * Used when moving around the space
  * Allows remote access to ShowTouch
  * Most commonly used device outside the control room
* **Mobile Phone**&#x20;

#### **Radios (Communication)**

* **Channel 2**
  * Used for communication with Front of House
  * FOH may also contact you here, even if not intended
* **Channel 4**
  * Shared channel (Experience + Tech)
  * Can become busy
  * Used when communicating across departments

⚠️ Important:

* Radio communication is **public**
* Avoid escalating issues prematurely (e.g. announcing faults without confirmation)
* When needed, communicate directly with your supervisor or via private channels (e.g. calls or tech chat)

#### **Additional Devices**

* Backup/control PCs located backstage
* Provide access to the same systems if required
* Rarely used during normal operation
* Secondary access if needed



## **3. Monitoring (Primary Responsibility)**

Although the show is automated, monitoring is the operator’s main role.

Operators are responsible for:

* Watching sequence timers and countdowns
* Ensuring all rooms are running correctly
* Identifying sync issues or faults
* Responding to system alerts

#### **Alert System (HELP / RECEIVE)**

The system includes an alert function:

* **HELP**
  * Indicates a call or issue
  * Triggers a sound and light notification
* **RECEIVED**
  * Used to acknowledge and respond to the alert

There are multiple types of alerts (covered in another section), and operators should:

* Identify the alert type
* Respond appropriately using the system



## **4. Cue Triggering**

While the show runs automatically during operation, **some cues must be triggered manually at the start of the day**.

#### **Start of Day Triggers**

Operators are required to manually start:

* **Neighbourhood ON**
* **Hallway Show lighting**
* **Looping/background tracks**
* **Foyer ON (via start-of-day system)**

These elements **will not run automatically** unless triggered.

#### **Ongoing Operation**

After initial setup:

* The show runs automatically
* No continuous cue triggering is required

The operator’s role shifts to:\
👉 ensuring all systems remain in the correct state\
👉 confirming looping elements continue as expected



## **5. System Interaction (Operator Behaviour)**

System interaction refers to how operators engage with the system during operation.

#### **Key Principles**

* Set up correctly at the start of the day
* Avoid unnecessary interference during live operation
* Only adjust systems when required
* Do not access programming systems (e.g. WinScript)
* Avoid manual audio adjustments unless trained

#### **Operational Awareness**

* Not all controls are meant for regular use
* Many functions exist for troubleshooting only
* Poor or unnecessary interaction can disrupt the show experience
