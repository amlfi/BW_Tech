# 3.3.1 / Rehearsals

<details>

<summary>How to be a Rehearsal Tech</summary>

If you are the Tech assigned to facilitate Experience rehearsals, you will work alongside the ASM and Experience Management to make sure everything runs smoothly for the actors without much assistance from Technical staff.

#### **Once PAV 1 is clear**

* [ ] Close MAX8 program on Audio Server 1&#x20;

- [ ] Open Rehearsal show file&#x20;

* [ ] Click Reload Sound Files and wait for it to reload

**Once PAV 2 is clear**

* [ ] Close MAX8 program on Audio Server 2

- [ ] Open Rehearsal show file

* [ ] Click Reload Sound Files and wait for it to reload
* [ ] Switch to Radio Channel 1\


**IPADS**

* Make sure BOTH ipads are fully charged.

- In ShowTouch, select Version 2 Operations Centre on both ipads.

* V2 content can only be played from the Emergency Stop panel on the ipads; they shouldn’t press the physical living room buttons\


**TEST**&#x20;

Go to the Emergency Stop menu and play each room to check the correct audio files are playing

If it is still playing Version 1 audio:

* Click Reload sound files on MAX8
* Close and reload rehearsal show file
* Check the Max console and see if any errors are popping up related to finding the sound file. If it can’t find the file, click on the room and click Patching Mode in the bottom menu of the window. On the far right in the area labelled REH, it should read (e.g. for Living Room Mac) LivingRoom1\_Rehearsal.aif. Check the folder in Documents/Max8/Library/AudioFiles to make sure a matching audio file with that name is there. If it isn’t, the audio files can be found and downloaded from Dropbox (Tech-HVKBW/03\_Sound/BW v2 Audio) and renamed to match.



**TURN OFF**

Toilet niches (so they don’t activate when walking past)&#x20;

* Mac Living Room Bottom Distro - Switches 7, 10, 11
* TVs **-** Backyard, Chilli (both sides), plus any on the side not in use.\


### **REHEARSAL TIME**

* Switch to Radio Channel 1 once all patrons have left the venue and let Experience know you are switching channels
* Coordinate with the ASM and Experience Management and let them know you are the tech assigned to rehearsals
* Give both ipads to the SM - they will allocate them to those who need them
* If they’re not across how it works, show them and test the rooms with them if they have time
* Rehearsals start with warmups in the backyard or party room - use this time to make sure they’re fully across using the ipads and that everything is working as it should
* The Dome content needs to be manually played from the Dome PC - load the V2 content and tell ASM to radio when they want to play Dome
* Be on call for experience - keep your radio on you at all times



**END OF DAY**

* [ ] Close MAX8 and load the current sound show file on Audio Servers 1 & 2
* [ ] Click Reload Sound Files and test using ShowTouch and the physical button in the living room.
* [ ] Reset any audio level adjustments made.
