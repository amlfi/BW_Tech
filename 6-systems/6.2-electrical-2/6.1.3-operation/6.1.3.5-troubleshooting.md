# 6.4.3.5 / Troubleshooting

<details>

<summary>Audio System Network Config</summary>

Devices: Audio Server 1, Audio Server 2, NX Witness Computer



This Guide uses Audio Server 1 as an example just know that all the following information is interchangeable with Audio Server 2 with minor adjustment



Checking The Port Configuration (Audio Server 1)

1. Open Network Settings&#x20;
2. You will see the networks listed out
3.
   1. Wifi
   2. OSC
   3. DANTE
4. Click on the DANTE Network
5. Click Details in the top right corner
6. Click Hardware from the Menu list on the Left
7. You Should now see the follow
8.
   1. MAC Address - (Unique Alphanumeric Code XX:XX:XX:XX:XX:XX )
   2. Configure - Automatically
   3. Speed - 1000baseT
   4. Duplex - full-duplex
   5. MTU - Standard (1500)



Cross Checking With Unifi (NX Witness Computer)

1. Open Google Chrome
2. Open Unifi from the Bookmarks Bar&#x20;
3. On the left hand side you will see several icons indicating the following
4.
   1. Dashboard
   2. Topology
   3. Unifi Devices
   4. Client Devices
   5. Ports
   6. Radios
   7. Insights
   8. Admins
5. Click on Ports
6. In the top left corner you will see a drop down menu go ahead and click on down arrow
7. You should now see a list of all the Switches on the network
8. Select SW\_USW Pro\_Tech Control
9. You should see a virtual switch on the screen that corresponds with the physical unit located in the control room rack
10. We only need to concentrate on Ports 11, 12 ,13 & 14
11.
    1. 11 - Audio Server 1 Dante
    2. 12 - Audio Server 1 OSC/Vision
    3. 13 - Audio Server 2 Dante
    4. 14 - Audio Server 2 OSC/Vision
12. Above/Below the green highlighted ports you will see a picture of a Monitor
13. Click on the monitor above Port 11 and a popup will appear on the right hand side of the screen
14. In this menu you should see the following
15.
    1. Virtual Network - Vlan09 - Dante (112)
    2. Virtual Network Trigger - SW\_USW\_ Pro\_Tech Control
    3. IP Address - 10.150.112.20
    4. MAC Address - 00:e0:4c:68:3e:cf
    5. Hostname - Audio-Server-1
    6. Manufacturer - Realtek Semiconductor Corp.
    7. Down Pkts/Bytes
    8. Up Pkts/Bytes
16. We want to cross check and ensure that the MAC Address here matches with the MAC Address on the Audio Server 1 - Dante Network



What To Do In The Event The MAC Address Doesn't Match (Audio Server 1)

1. Open Network Settings&#x20;
2. You will see the networks listed out
3.
   1. Wifi
   2. OSC
   3. DANTE
4. Click on the OSC Network
5. Click Details in the top right corner
6. Click Hardware from the Menu list on the Left
7. You Should now see the follow
8.
   1. MAC Address - (Unique Alphanumeric Code XX:XX:XX:XX:XX:XX )
   2. Configure - Automatically
   3. Speed - 1000baseT
   4. Duplex - full-duplex
   5. MTU - Standard (1500)
9. If the MAC Address here matches the MAC Address on Unifi you can safely assume that the Ethernet Cables are plugged into the wrong ports on the back of the Audio Server 1 Mac Mini
10.
    1. If not repeat the above steps on Audio Server 2 until you find the matching MAC Address
11. Once you’ve identified the location of the matching MAC Address unplug and swap the  corresponding ethernet cables on the back of the Mac Mini (Audio Server 1)
12. Now Restart the Computer
13. Once the Device has rebooted open Network Settings&#x20;
14. Click on the Dante Network&#x20;
15. Click Details&#x20;
16. Click Hardware and you should find the MAC Addresses should now match across Unifi and the Device

Note: you will have to repeat the above process on all Audio Server Networks until the MAC Addresses match the Corresponding Ports in Unifi

Port 11 - Audio Server 1 Dante

Port 12 - Audio Server 1 OSC/Vision

Port 13 - Audio Server 2 Dante

Port 14 - Audio Server 2 OSC/Vision
